TomlWhy
TOML looks like YAML and INI, and parses like neither.
Open the app
port = 0755 is an error (no leading zeros). x = .5 is an error. ok = True is an error. t = 07:32:00 is a local time, not a string.

What it does

  • Takes key = value lines and shows the TOML 1.0 type and parsed value of each, or the exact rule it breaks.
  • Covers integers (decimal, hex, octal, binary, underscores), floats, inf and nan, booleans, the four date and time types, and single-line strings.
  • Runs in your browser. Nothing is uploaded.

How far to trust it

  • Rules read from the TOML 1.0.0 spec on toml.io. Compared with Python tomli 2.4.1 on 4000+ cases. It does not parse arrays, inline tables, tables or multi-line strings. It rejects integers beyond 64 bits and times without seconds, as TOML 1.0 requires; tomli accepts both.
